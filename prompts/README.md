# Prompt library

Every prompt that worked well is saved here so the team can reuse it (syllabus idea: share prompt libraries).

File name: `<exercise-id>_<short-name>.md` — for example `2.2.1b_refine-acceptance-criteria.md`

Each file contains:
1. **Purpose** – the test task
2. **Technique** – zero-shot / few-shot / prompt chaining / meta prompting
3. **Prompt** – the full text, using the six parts: Role, Context, Instruction, Input data, Constraints, Output format
4. **Model used** – e.g. ChatGPT, Claude, llama3.1:8b
5. **Result quality** – what worked, what failed, score
